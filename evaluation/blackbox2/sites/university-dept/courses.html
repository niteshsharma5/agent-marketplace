Course Catalog

The table below lists the core undergraduate course offerings for the coming academic year. Course descriptions are intentionally kept close to the official catalog language used by the registrar. Students should consult their academic advisor before finalizing a schedule, as prerequisite chains and seat availability vary by term.

Code Title Credits Description
CS 101 Introduction to Programming 4 An introduction to computational problem solving and programming using a modern high-level language, covering variables, control flow, functions, basic data structures, and an introduction to debugging and testing practices, intended for students with no prior programming experience.
CS 210 Data Structures and Algorithms 4 A study of fundamental data structures including lists, stacks, queues, trees, and graphs, together with algorithm design techniques and complexity analysis, with programming assignments that require students to implement and analyze the structures and algorithms covered in lecture.
CS 305 Computer Systems and Architecture 3 An examination of the organization of modern computer systems from the logic gate level through the instruction set architecture level, including memory hierarchies, pipelining, and an introduction to assembly language programming.
CS 340 Database Systems 3 Principles of database design and implementation, including the relational model, normalization, query languages, transaction processing, and an overview of alternative data storage paradigms used in modern applications.
CS 412 Artificial Intelligence 3 An introduction to the principal techniques of artificial intelligence, including search, knowledge representation, planning, and an introduction to machine learning methods, with programming assignments in each major topic area.
CS 455 Human-Computer Interaction 3 Principles and methods for designing, prototyping, and evaluating interactive systems, including usability testing, accessibility considerations, and iterative design practices grounded in current research literature.
