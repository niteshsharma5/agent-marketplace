Frequently asked questions

Is the wool itch-free?

Our merino is fine-gauge and combed before weaving, so most wearers find it comfortable directly against the skin. If you're sensitive to wool, we recommend a thin base layer.

How should I choose between S and M?

The coat has a relaxed wrap fit. If you're between sizes, most customers size down for a more tailored look, or size up to layer over sweaters. See the full size guide above.

Can I return it if the fit isn't right?

Yes. Unworn items with tags attached can be returned within 30 days of delivery for a full refund; see Shipping & returns above for details.
