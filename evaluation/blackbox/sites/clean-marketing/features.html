Features

Every Loomstack plan includes the same core toolkit: task boards, a timeline view, shared docs, and guest access. Higher plans add more automation and storage, not extra features locked away.

Task boards

Loomstack task boards use three columns by default — To Do, In Progress, and Done — though you can rename or add columns to match how your team already talks about work. Each card can hold a description, a due date, an assignee, and file attachments. Moving a card between columns is a single drag; there's no separate "update status" step to remember.

Timeline view

The timeline view plots every task from your boards as a horizontal bar against the calendar, so overlapping deadlines and gaps in the schedule are visible at a glance. In the example below, "Research" and "Wireframes" run in parallel during week one, "Build" spans into week two, and "Launch" is scheduled for the last two days of the sprint.

Shared docs

Every project has a docs tab for meeting notes, briefs, and specs, using a plain-text editor with headings, checklists, and tables. Docs live next to the board they belong to, so new team members can find context without searching old email threads.

Guest access for clients and contractors

Add clients or freelance contractors as guests on a specific project. Guests can view boards and leave comments but cannot edit tasks, invite others, or see your other projects. This keeps client communication in one place without giving up control over your workspace.
